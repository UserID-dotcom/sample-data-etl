#サンプルデータETLパイプライン

#概要
業務現場における、粒度違い・表記揺れのある未整備データを、自動で収集・クレンジング・統合し、スプレッドシートやBigQueryへ格納することで、BI分析可能な形にデータを整えるETLパイプラインのサンプルです。
*実務で構築したパイプラインのロジックをベースに、ダミーデータでデモノートブックとして再構成しています。

#処理内容
- Googleドライブ上の、エクセル・CSVファイルの走査・収集（os, chardet, pandas）
- CSVファイルの、文字エンコード変換（pathlib, unicodedata）
- 収集データの抜粋、要・不要列の抜粋
- 収集データのクレンジング、属性の付与・粒度の統一・正規化・インメモリ一時保存（re, SQLite, :memory:）
- 収集データの統合（変数名：clean_df）
- 統合データ保存①（Googleスプレッドシート編）
- 統合データ保存②（.dbファイル編）
- 統合データ保存③（BigQuery編）
- （粒度の違いを見越し、任意のデータ単位で収集・クレンジングするようにしています）
- （不要だが加工する見出し列名は、後で確認できるように”中間列_〇〇”として保存しています）
- （率や割合といった係数指標は、BIツール内で計算する想定です）
